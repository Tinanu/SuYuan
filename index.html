维护者 · 如何更新下载文件 / 部署到 GitHub Pages
  1. 把安装包放进 appAPK/ 目录，建议命名为 溯源.apk（放别的文件也行，页面会全部列出）。
  2. 在项目根目录执行 node build.js，自动刷新 releases.json 里的版本、大小、日期与校验值；版本号在 build.js 的 SITE.version 中修改，与 App 内 config.js 的 LOCAL_VERSION 保持一致。
  3. 提交并推送：git add . && git commit -m "release" && git push。注意 .gitignore 不能排除 appAPK/，否则线上没有文件可下。
  4. GitHub 仓库 → Settings → Pages → Build and deployment 选 Deploy from a branch，分支 main、目录 / (root)，保存后等一两分钟即可访问。

即使忘记跑 build.js，页面也会探测 appAPK/溯源.apk，并把目录里的其它文件作为备用下载。单文件超过 100 MB 时，GitHub 仓库会拒绝提交，建议改放 GitHub Releases。

常见问题

下载前先看这里

需要联网吗？

不需要。题库、解析、口诀与二十八脉动态页都内嵌在应用里，飞行模式也能练；只有「检查更新」会访问网络。

在微信里点「下载」没反应？

微信内置浏览器会拦截 APK 下载，页面会自动跳到独立的「请在浏览器中打开」引导页（一张带 ① ② 指引的完整手机示意图看完）。点屏幕右上角「···」，在底部面板第一行找到「在浏览器中打开」，系统浏览器会自动回到下载页再下载；找不到该选项就点第二行「复制链接」，粘贴到浏览器地址栏访问。

iPhone / iOS 能用吗？

目前只提供 Android 安装包（APK），iPhone / iPad 暂不支持。

安装时被系统拦住怎么办？

在系统提示中允许「安装未知来源应用」；部分机型还需临时关闭「纯净模式」或「安装监控」，装完可重新开启。

提示「应用未经验证」安全吗？

当前是开发调试版（debug 签名），系统因此会给出提示。文件由本站直接提供，下载后可用上方 SHA-256 核对完整性；确认一致再安装，不要从第三方渠道获取同名安装包。

覆盖安装会丢成绩吗？

学习档案与成绩保存在本机，应用内提供成绩单与历史记录；大版本更新前建议先记录一下重要数据。

内容可以当作诊疗依据吗？

不可以。本应用用于中医经典内容的记忆与练习，不构成诊断、治疗或用药建议，身体不适请就医。
